# TRON Consultancy website

Static single-file site (index.html) hosted on GitHub Pages.

- `index.html` – the entire website (HTML, CSS, JS, logo embedded)
- `CNAME` – the custom domain served by GitHub Pages (edit if the domain changes)
- `.nojekyll` – tells GitHub Pages to serve files as-is

To update the site, edit `index.html` and push to `main`. GitHub Pages redeploys automatically.
